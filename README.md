## Overview

This project was created to explore desktop application development using Delphi and database management with MySQL. The application focuses on implementing CRUD (Create, Read, Update, Delete) functionality while providing a simple and intuitive interface for managing employee records.

---

## Features

* Add new employee records
* Edit existing employee data
* Delete employee records
* Display data using DBGrid
* Store and manage data in a MySQL database
* User-friendly desktop interface

---

## Technologies

| Technology   | Description                                        |
| ------------ | -------------------------------------------------- |
| Delphi (VCL) | Framework used for desktop application development |
| MySQL        | Relational database management system              |
| ODBC Driver  | Database connectivity between Delphi and MySQL     |
| XAMPP        | Local development environment for MySQL services   |
